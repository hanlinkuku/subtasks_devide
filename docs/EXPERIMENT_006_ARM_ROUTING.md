# 实验 006：正式流程中的手臂信息贯通

预先登记。只改变手臂来源及其传递，不改运动阈值、场景类别、采样和模型参数。分别使用原有平移区间检测检查双臂；仅一臂存在区间时选择该臂，无法唯一选择时明确报告，不默认左臂。

选择结果必须同步决定候选遥测、腕部原分辨率输入、提示里的相机与末端名称，以及最终导出手臂。现有左腕的原路径和请求内容保持一致，以便严格比较本轮前后。

验收：两条实际轨迹自动选中左臂，最终内容与本轮前提交完全一致；交换遥测字段后选择随之转移；用有区别的左右测试图和坐标检查实际构造的模型请求，不把路由测试称为真实右臂识别准确率。多臂协同及无明显平移的交互不在当前选择器可自动处理的范围，不能静默写成左臂或无动作。

右腕不套用左腕固定屏幕区域的闪光补查；仍进行原来的全图屏幕比较与逐帧锚点细化。该补查缺口需有右腕真实数据后评估，不能假定对称相机布局。

## 结果与采用范围

两条实际轨迹的选择报告均为左臂，右臂没有触发原有平移区间规则。正式流程已接入该选择，不再由调用者默认选左臂。完整缓存运行后，两条最终标注的全部字段与上一提交 `546965f` 一致，新增请求 0。报告位于 `outputs/experiments/006_arm_routing/`，逐臂数据位于 `outputs/automatic/arm_selection/`。

62 项检查通过，其中新增检查包括：左右遥测交换、两臂均有运动、两臂无平移、右腕缺帧、实际请求中的右腕图片与右末端坐标/增量，以及主流程两轮候选对所选手臂的传递。彩色测试图仅验证图片路由，不是真实右臂识别样本。

采用范围是当前单一平移操作臂的完整信息传递。两臂都运动或无明显平移时，流程现在明确要求复核，不能自动判断协同动作或静态交互；这也意味着纯静止轨迹不会仅凭遥测被自动写成 wait。旧多视角复核实验仍限原左臂数据，对右臂明确拒绝运行。当前两条数据没有真实右臂操作，不能把路由通过当成右臂任务准确率验证。

尚未解决的独立问题：默认交互类别仍是按钮操作；目标类型、屏幕锚点和运动几何规则仍有场景依赖；候选期间的主要视觉证据仍来自所选腕部，未证明头部时序信息可以省略。后续应逐项实验，不把本轮称为通用划分完成。
