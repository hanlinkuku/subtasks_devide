# 第二轮：可见事实与动作解释分离

## 实施范围

固定流程，无 Agent，模型仍为 Qwen3-VL-32B。对上一轮的 10 条分歧窗口重新提取可见事实，然后由确定性规则检查证据充分性。时间范围来自上一轮分歧，但事实提取提示词不包含候选动作名称、上一轮解释或人工参考答案，因此是提示词层面的标签隔离，不是独立选样。

事实提取保留四视角与左腕原分辨率细节；每窗口最多 18 个时刻，明确标记是完整逐帧还是均匀采样。记录相对运动、屏幕变化、局部尖端运动、按钮可见形变、物体可见脱离、遮挡等，引用实际输入帧和视角。

规则检查：单独屏幕变化、遮挡或相对运动不足以确认独立交互；局部尖端运动与屏幕变化共同出现，最多形成交互假设；可见形变或物体脱离仅形成待核实候选，不直接写入新动作或精确边界。所有输出继续保留不确定性。

## 两条轨迹的结果

| 轨迹 | 原有分歧条目 | 证据不足 | 交互假设 | 直接形变/释放候选 | 已确认新增动作 |
|---|---:|---:|---:|---:|---:|
| episode_000000 | 8 | 5 | 3 | 0 | 0 |
| episode_000001 | 2 | 2 | 0 | 0 | 0 |

这些条目可能重叠，不能理解成独立动作数量。7 条证据不足不等于证实了 7 个误报；3 条交互假设也不等于有 3 个新动作。当前规则有意保守，还没有独立准确性评估，不报告精确率或召回率提高。

例：第二条轨迹 147–150 帧此前被解释成又按了一次升温按钮。这次事实提取记录了更早的屏幕显现及随后的稳定显示，没有提供按钮形变或可区分的新推进证据。规则输出“证据不足以确认独立交互”，原始意见仍可追溯。

## 仍有的问题

- 提取出的“事实”仍是模型观察，可能错误，不能当作真值。
- 模型偶尔仍在描述中写“持续接触”等推断。当前记录 claim_flags 并排除相应记录作为清晰证据；有限短语检查可能有漏检或误标，不是完整语义校验器。
- 同一窗口内尖端运动与屏幕变化同时存在，不证明因果或独立按压，因此只输出假设。
- 当前输出只检查上一轮分歧，没有重估全部边界；原来的 11 段、7 段标注保持不变。

## 文件与验证

- `fact_review.py`：事实校验与固定解释规则。
- `outputs/automatic/fact_review/`：两条轨迹的逐项事实与解释结果。
- `outputs/automatic/multiview_refined/evidence/*/facts_v1_*/`：新图片、完整 context 和模型原文。
- 工作台原多视角复核报告中增加第二轮结果。
- 30 项 Python 检查通过，包括不可见帧引用、错误视角、单线索不足和推断性接触描述不能作为直接证据。

本轮收获是把“模型声称发生动作”与“目前有何证据”分开记录和使用。后续需要验证事实本身，特别是屏幕变化和相对位移，再讨论是否能自动解决剩余假设。
