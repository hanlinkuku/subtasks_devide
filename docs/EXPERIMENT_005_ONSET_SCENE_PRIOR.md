# 实验 005：起点提示移除墙面与指定尖端预设

预先登记：只改变起点提示第一句，删除面板安装方式、夹爪颜色和指定操作尖端的断言；保留左腕相机这一输入元信息，要求从实际画面辨别操作端和目标。

屏幕比较提示、响应锚点、候选、逐帧图片、遥测、采样、模型和参数保持不变。原提示和去预设提示各运行 5 次起点调用，其余阶段复用相同输入的真实缓存。独立输出运行完整流程，正式结果不覆盖。

验收优先级：动作顺序与保持段完整性；逐项记录起点差异与模型理由。微小差异不据此调阈值，也不称准确率改善。明显将大范围接近纳入 press 或将起点推迟到响应之后属于退化。若缺少证据裁定，保留基线。屏幕变化锚点仍为场景限制，不能称该实验消除了整个流程的场景假设。

采用结论：按用户“不优先处理人工难区分的微小差异”的新口径，接受本处不确定的 3 帧变化以去除显式墙面和指定尖端先验，不调整阈值。未改变任务分类、未丢失保持段；这不是精确起点已获证明，也不形成所有任务通用的 3 帧容差。当前原提示和新提示仍会把遥测推进解释为接触/压力，模型解释不是力传感器证据。

采用范围仅为起点提示第一句。屏幕状态检测、左腕视角和运动规则仍需后续单独验证。结果保留在 `outputs/experiments/005_onset_scene_prior/`，冻结 v1 基线不修改。
