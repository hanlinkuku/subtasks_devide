# 实验 003：移除视觉交互提示的具体场景预设

预先登记。唯一变量是首次交互核实提示的场景先验：删除墙面温控面板、未抓持、左侧尖端是操作端等断言，改为要求从画面观察。保留真实的左腕相机元信息、候选、图片、帧顺序、后续按钮交互问题、模型和参数。

范围仅为当前 5 个交互首次视觉核实，不代表完整通用动作识别。分别记录是否支持交互、起止帧变化及原始证据；有退化或不确定时不替换主流程。按压任务类别、左腕输入及后续屏幕锚点假设仍然存在。本实验不把工作参考送入推理。

为区分提示变化与模型自身波动，另做每个交互一次原提示的新调用，参数和请求不变，仅使用独立缓存位置。共 5 个去先验请求和 5 个原提示对照请求。单次重复不足以估计稳定准确率，但可以发现明显的同输入波动。

以上是首次视觉核实建议，不是经过运动撤离及起点细化后的正式帧边界。两组均支持全部 5 个交互，均未提出额外动作。本次原提示重复的边界全部与历史一致；去场景先验组两处变化。

第一个交互将屏幕恢复显示作为结束依据，提前 7 帧，与推进及保持直到持续撤离的操作定义不一致。因此未证明首次视觉边界质量不退化，暂不采用。另一次提前 2 帧缺少精确真值，不能标为改善。单次控制不能证明随机波动不存在或建立统计因果关系。
